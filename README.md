🎸 Guitar & AI Chords Generator
Ứng dụng hỗ trợ chơi nhạc tích hợp AI, giúp người dùng tra cứu hợp âm, tạo hợp âm tự động từ lời bài hát và quản lý thư viện âm nhạc cá nhân.

🚀 Tính năng chính
Sáng tạo hợp âm với AI: Tự động phân tích và gợi ý hợp âm chuẩn xác từ lời bài hát chỉ trong vài giây.

Thư viện hợp âm: Cập nhật liên tục các bài hát mới nhất kèm hợp âm chi tiết.

Công cụ hỗ trợ: Tích hợp bộ máy lên dây đàn (Guitar Tuner) trực tuyến.

Cộng đồng: Đăng tải và chia sẻ bài hát tự sáng tác hoặc các bản phối mới.

Đa nền tảng: Giao diện tối ưu cho cả trình duyệt Web và thiết bị di động.

🛠 Công nghệ sử dụng
Frontend: React

Backend: Spring Boot, Node.js

UI/UX: Tailwind CSS, Font Awesome

Database: (Tùy chọn: MongoDB/PostgreSQL)
